## 🧭 Sobre mim

Sou estudante de Tecnologia e estou construindo, passo a passo, minha trajetória como **desenvolvedor web**. Meus projetos práticos passam por **HTML, CSS, JavaScript e Python/SQL**, sempre buscando entender não só *como* uma solução funciona, mas *para quem* ela funciona.

Tenho interesse especial em **acessibilidade e inclusão digital** — acredito que código bem escrito também é código que não deixa ninguém de fora. Estou no início da carreira, mas trato cada repositório como uma oportunidade de praticar boas práticas de verdade: nomes claros, código organizado e documentação que qualquer pessoa consiga entender.

## 🌱 Minha jornada

Como todo desenvolvedor em formação, meu percurso é feito de pequenos projetos práticos — telas de login, sistemas de reserva, interfaces bancárias fictícias e páginas de portfólio. Cada repositório aqui representa um passo dessa caminhada: um conceito testado, uma tecnologia nova experimentada, um erro corrigido.

Em vez de esconder esse processo, prefiro deixá-lo visível. Um perfil organizado não significa só projetos "perfeitos" — significa mostrar com clareza o que cada coisa é e por que ela existe.

## 🧠 Princípios que sigo

- ♿ **Acessibilidade primeiro** — HTML semântico, contraste adequado, navegação por teclado
- 🧹 **Código limpo** — nomes descritivos, funções pequenas, comentários só quando necessário
- 📚 **Documentação honesta** — README que explica de verdade o que o projeto faz
- 🔁 **Consistência** — mesma convenção de nomes e estrutura em todos os repositórios
- 🧪 **Aprender fazendo** — cada projeto testa um conceito novo, mesmo que simples
